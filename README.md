# IC 555 Based Audio-Visual Alert System

## 📌 About the Project

This project is an IC 555 Timer based audio-visual alert system designed and simulated using Tinkercad.

The circuit provides both visual and audio indications through a green LED and a piezo buzzer when the alert output is activated.

## 🎯 Objective

The main objective of this project is to understand the practical application of the IC 555 Timer in designing a simple electronic alert circuit.

## 🛠️ Components Used

- IC 555 Timer
- Green LED
- Piezo Buzzer
- Push Button
- 1 kΩ Resistors
- 330 Ω Resistor
- 100 nF Capacitors
- 9V Battery

## 💻 Simulation Platform

**Tinkercad**

The circuit was designed, connected, and tested virtually using Tinkercad.

## ⚙️ Working Principle

The IC 555 Timer is used as the main control element of the circuit.

When the circuit is powered and the alert condition is activated, the output of the 555 Timer drives:

- **Green LED** → Visual indication
- **Piezo Buzzer** → Audio indication

Thus, the circuit provides an audio-visual alert.
